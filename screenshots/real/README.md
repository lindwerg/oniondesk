# Кадры встроенной помощи

Включены только 26 PNG, на которые ссылается точный allowlist `GUIDE_SHOTS` клиента. Каждый кадр просмотрен отдельно на отсутствие личных данных владельца и секретов. Хеши и размеры находятся в [списке](../../docs/GUIDE-IMAGE-MANIFEST.json). Это локальный preview до финального privacy review перед push.

Сохранены исходные pixels без перерисовки. В кадрах присутствуют стандартные имена пользователя/host Whonix, тестовый пользователь `oniondesk-gui`, публичные пустые формы провайдеров, публичный Tor bridge и лабораторные значения systemd. Они не являются сведениями о личном сервере или устройстве владельца. Платёж, SMS и регистрация аккаунта не выполнялись этими кадрами.

Наличие настоящего экрана не доказывает прохождение полной цепочки. Подписи в UI отдельно ограничивают emulator/TCG, первый экран подключения и другие промежуточные результаты. Raw provenance JSON, private proofs и пользовательские журналы отсутствуют.
