# OnionDesk для Linux

Полностью извлеките комплект и откройте файл **OnionDesk** без расширения в папке приложения. Python, команды терминала и отдельная установка GPG получателю готового пакета не нужны. Если файловый менеджер требует разрешение, откройте свойства файла → «Права» → разрешите выполнение как программы. Названия пунктов зависят от рабочего стола.

Переносите комплект целиком. Рядом с программой нужна папка `_internal`, а официальный offline Data должен оставаться в поставляемом размещении. Мастер откроется в браузере по умолчанию; завершайте его кнопкой выхода. Неполный или повреждённый комплект останавливается с ошибкой.

Требования: 64-разрядный Linux x86_64 или aarch64 с glibc 2.36+, графический рабочий стол и обычный браузер. Alpine/musl и старые системы этой сборкой не покрыты. На Linux ARM64 нет проверенной стабильной официальной сборки Tor Browser; наличие ELF не подтверждает готовность всего маршрута. Для подготовки Android по USB Google не публикует официальный Linux ARM64 Platform Tools для закреплённой версии.

Для записи USB нужны polkit с `pkexec`, графическое подтверждение прав и стандартные средства работы с дисками. Права запрашиваются только для записи выбранного носителя; не запускайте весь мастер от имени администратора. Tails предназначен для совместимого компьютера Intel/AMD x86_64, даже если флешку готовят на ARM64. В полном Data-комплекте образ проверяется локально; отсутствие offline Data не отменяет проверки и ограничения сетевого маршрута.

Лицензии Python и библиотек находятся в `licenses/python`, Debian — в `licenses/debian`, GnuPG — в `_internal/tools/gpg/licenses`. Происхождение готовой сборки находится в `BUILD-PROVENANCE.json`, проверяющего модуля — в `_internal/tools/gpg/SOURCE-PROVENANCE.json`.
