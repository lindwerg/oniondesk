# Участие в закрытом preview

Изменения принимаются только в пределах доступа, предоставленного владельцем проекта. Публичность репозитория, приглашение участников и лицензия не меняются через обычный вклад.

Опишите конкретную проблему, ожидаемое поведение и способ воспроизведения. Сохраняйте договорённости клиента/сервера и защитные проверки. Поведенческое изменение должно включать соответствующий тест, а исправление ошибки — регрессионную проверку, когда это практически возможно. UI проверяйте визуально на широком и узком экране с синтетическими данными.

Не добавляйте реальные пароли, seed, адреса сервера, идентификаторы устройств, пользовательские профили, сырые журналы, downloaded executables или большие образы. Не ослабляйте подписи, allowlist, типизацию или тесты ради успешного прогона. Для доказательства используйте контролируемые fixtures; известные ключи теста помечайте TEST ONLY.

Перед review проверьте итоговый diff и [проверки разработки](docs/DEVELOPMENT.md). Укажите фактический результат, пропуски и непроверенное. GitHub Actions и платные runners не добавляются без отдельного решения владельца. Проблемы безопасности описывайте по [SECURITY.md](SECURITY.md).
