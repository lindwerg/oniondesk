# Сообщить о проблеме безопасности

Проект находится в закрытом preview. Не публикуйте уязвимости и пользовательские секреты вне согласованного доступа. Если в private-репозитории включён GitHub Private Vulnerability Reporting, используйте вкладку Security → Report a vulnerability. Наличие этой функции сейчас не заявлено.

Если закрытый канал не настроен, запросите его у владельца проекта через уже известный вам способ связи. Этот документ не придумывает адрес электронной почты и не создаёт новый публичный канал.

Для первичного отчёта достаточно версии, ОС/архитектуры, затронутой функции, ожидаемого/фактического поведения и безопасного воспроизведения на синтетических данных. Не присылайте seed, пароли, OTP, private keys, содержимое кошельков, реальные device IDs и необработанные пользовательские логи. При необходимости доказательства готовятся на disposable-стенде.

Не испытывайте проблему на чужом оборудовании, чужом сервере или данных без разрешения. Поддержка preview и сроки исправления определяются владельцем; наличие этого файла не обещает bug bounty, SLA или завершённый независимый аудит.
