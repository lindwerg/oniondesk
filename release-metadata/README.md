# Публичные исторические metadata

Здесь сохранены только точные code-pinned публичные ключи издателей, подписи, подписанные списки хешей, лицензии и два Android текстовых документа. Закрытых ключей, пользовательских настроек, APK, исполняемых файлов и дисковых образов здесь нет.

`tools/prepare-data.py` копирует эти файлы в нужные имена большого комплекта после сверки с каталогами кода. Оригинальные `.key` с public signing key хранятся здесь под расширением `.asc`, чтобы не смешивать их с секретными ключами. Android и desktop Tor используют одинаковый публичный ключ по одному закреплённому SHA.

`FILES.json` — перечень для аудита; этот JSON не расширяет доверенные пути, хеши или URL в коде. Лицензии не перелицензируются. Источники бинарников описаны в каталогах и [разработке](../docs/DEVELOPMENT.md).
