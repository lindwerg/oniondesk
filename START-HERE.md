# Начните здесь

Это бесплатная закрытая предварительная версия OnionDesk. Новые комплекты для запуска одним нажатием ещё не опубликованы; графический запуск на всех четырёх системах пока не подтверждён. На главной странице можно выбрать свою ОС и посмотреть статус. Файлы исходников для установки не нужны.

**[Видео, презентация и руководство опубликованы в выпуске v5](https://github.com/lindwerg/oniondesk/releases/tag/preview-2026.10.16-v5).** Все шесть вложений повторно скачаны из GitHub с совпадением размеров и контрольных сумм. Видео содержит 105 сцен без озвучки, презентация — 105 слайдов, руководство — 260 страниц.
