# Начните здесь

Обновлено: **2026-10-17**.

OnionDesk — бесплатный выпуск с открытым исходным кодом. Аккаунт GitHub для скачивания не нужен. Для установки выбирайте ZIP своей ОС; GitHub Source code ZIP предназначен для разработчиков.

1. [Скачайте небольшой ZIP своей ОС](README.md#программа-для-вашего-компьютера): от 5,4 до 19,1 МБ.
2. Полностью распакуйте ZIP в одну папку и сохраните всё содержимое.
3. [Откройте значок программы](docs/DOWNLOADS.md) и дождитесь окна мастера. OnionDesk сам загрузит около **3,8 ГБ** и проверит файлы. Для первой подготовки нужны интернет и не менее **20 ГБ** свободного места; Python и команды не нужны.

Первая загрузка идёт с GitHub по обычному HTTPS. При следующих открытиях программа использует проверенный локальный кэш. На Mac ресурсы находятся внутри `OnionDesk.app`; соседняя скрытая `.oniondesk` содержит лицензии. Сохраняйте весь распакованный комплект.

Linux ARM64 предназначен для подготовки и просмотра инструкций: этап с официальным Tor Browser на этой архитектуре недоступен. Готового Mac Intel нет. [Что фактически проверено](docs/VERIFICATION.md).

**[Видео, презентация и руководство опубликованы в выпуске v5](https://github.com/lindwerg/oniondesk/releases/tag/preview-2026.10.16-v5).** Все шесть вложений повторно скачаны из GitHub с совпадением размеров и контрольных сумм. Видео содержит 105 сцен без озвучки, презентация — 105 слайдов, руководство — 260 страниц.
