# Начните здесь

Это бесплатная закрытая предварительная версия OnionDesk. Для скачивания нужен аккаунт GitHub с доступом к приватному репозиторию. Полная проверка загрузки и запуска на всех четырёх ОС ещё не завершена. Файлы исходников GitHub Source code ZIP для установки не нужны.

1. [Выберите свою ОС и скачайте ZIP](README.md#программа-для-вашего-компьютера). Комплект занимает несколько ГБ; освободите не менее **20 ГБ** и дождитесь загрузки целиком.
2. Полностью распакуйте ZIP в одну папку, сохранив всё содержимое и папку `.oniondesk` рядом с программой.
3. [Откройте значок своей программы](docs/DOWNLOADS.md) и дождитесь проверки файлов и окна мастера.

Linux ARM64 предназначен для подготовки и просмотра инструкций: этап Tor Browser на этой архитектуре недоступен.

**[Видео, презентация и руководство опубликованы в выпуске v5](https://github.com/lindwerg/oniondesk/releases/tag/preview-2026.10.16-v5).** Все шесть вложений повторно скачаны из GitHub с совпадением размеров и контрольных сумм. Видео содержит 105 сцен без озвучки, презентация — 105 слайдов, руководство — 260 страниц.
