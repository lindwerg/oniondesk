# Результаты экспортированного дерева

Результаты прежнего рабочего комплекта не копируются как доказательство нового экспорта. Статус и границы — в [матрице проверок](../../docs/VERIFICATION.md). Сценарии сохранены для отдельного воспроизводимого прогона.

Необработанные логи и снимки реальных устройств в репозитории отсутствуют. README использует синтетические preview.
