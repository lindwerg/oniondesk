# OnionDesk: начать без команд

Обновлено: **2026-10-17**.

Эта инструкция описывает бесплатный выпуск OnionDesk с открытым исходным кодом. Аккаунт GitHub для скачивания не нужен; начните с [загрузки и статуса своей ОС](docs/DOWNLOADS.md). Все четыре небольших ZIP повторно скачаны из публичного Release с проверкой размеров и SHA-256. Полный первый запуск R5 проверен на Mac; [остальные проверки и их границы](docs/VERIFICATION.md) указаны отдельно. Подробное PDF-руководство, видео и презентация опубликованы [на странице выпуска](https://github.com/lindwerg/oniondesk/releases/tag/preview-2026.10.16-v5).

## 1. Выберите свой компьютер

Windows x64 открывает `OnionDesk-Windows.exe`. Для Mac Apple Silicon с macOS 15+ нужен Mac-пакет. Для Linux выбирайте вариант x86_64 или aarch64; необходимы графический рабочий стол, браузер и glibc 2.36+. Для Tor Browser на Linux x64 нужен обычный Linux Desktop с GTK3 и ALSA. Готового пакета для Mac Intel сейчас нет. Linux ARM64 в этом выпуске предназначен для подготовки и просмотра инструкций: этап с официальным Tor Browser отключён. Для полного маршрута используйте компьютер Intel/AMD x86-64 или поддерживаемый Mac. Подробнее — в [статусе этой ОС](docs/DOWNLOADS.md#linux-arm64).

Android и iPhone используются для входа в подготовленный кабинет. Это не варианты установки настольного мастера. Загрузка Tails с флешки предназначена для совместимого Intel/AMD x86_64 компьютера; Apple Silicon этим сценарием не покрыт.

## 2. Откройте комплект

1. [Выберите свою ОС и скачайте небольшой ZIP](README.md#программа-для-вашего-компьютера), от 5,4 до 19,1 МБ.
2. Полностью распакуйте архив в одну папку, сохранив всё содержимое, включая скрытую `.oniondesk` с лицензиями. На Mac ресурсы запуска находятся внутри `OnionDesk.app`; внешний runtime-пул не нужен.
3. На Windows откройте `OnionDesk-Windows.exe`, на Mac — `OnionDesk.app`, на Linux — файл запуска своей архитектуры. OnionDesk автоматически загрузит около **3,8 ГБ**, проверит и подготовит файлы, затем откроет окно мастера. Для первого запуска нужны интернет и не менее **20 ГБ** свободного места. [Точные действия и ограничения каждой ОС](docs/DOWNLOADS.md).

Первая загрузка выполняется с GitHub по обычному HTTPS и не заявляется как Tor-трафик. Подготовку можно отменить и повторить. При следующих открытиях программа проверяет и использует локальный кэш, в том числе без сети; Tor и внешние сервисы требуют соединения.

Загрузчик получает необходимые зависимости для запуска OnionDesk; доступность этапа Tor Browser зависит от архитектуры, как указано выше. Для отдельного Tor Browser на Linux x64 нужны системные GTK3 и ALSA. Устанавливать Python, вставлять команды в терминал и собирать приложение не нужно. Непроверенный или повреждённый комплект должен остановиться с ошибкой. Не заменяйте его файлами из случайных источников и не отключайте проверку подписи.

Mac-пакет имеет локальную подпись ad-hoc, без Apple notarization. Программа не должна просить отключить защиту системы целиком.

## 3. Подготовьте доступ

Откройте первый этап и выберите устройство с поддерживаемым официальным Tor Browser. Для Linux ARM64 в этом выпуске используйте другой совместимый компьютер. Подключите Tor согласно подсказкам своей ОС. Сам факт установки браузера ещё не означает установившееся соединение Tor. При другом экране используйте помощь текущего действия.

## 4. Подготовьте кошелёк и резервную копию

При необходимости создайте пустой кошелёк в защищённом хранилище. Сохраните 25 слов вне приложения и выполните проверку резервной копии. Не пересылайте слова, пароль, карточку доступа или одноразовые коды в Issues и отчёты. Получение XMR и переводы подтверждаете лично в совместимом официальном кошельке; мастер не выполняет переводы за вас.

## 5. Подготовьте флешку

Используйте собственный USB-носитель без нужных файлов. Перед записью мастер покажет выбранное устройство и потребует отдельное подтверждение стирания. Проверьте объём и название носителя. После записи дождитесь проверки результата. Для загрузки в Tails потребуются меню загрузки, выбор сети и при необходимости настройка bridges; эти действия выполняет владелец компьютера.

## 6. Подготовьте сервер

Проверьте требования мастера до оплаты. Выбранный сервер должен соответствовать поддерживаемой конфигурации; доступ к KVM и ресурсам подтверждает провайдер. Перед установкой сверяйте SSH-ключ. Подключение и передача установщика идут по предусмотренному маршруту через Tor. Успешная передача файлов ещё не подтверждает готовность гостевой Workstation.

Сервер и номер выбираете и оплачиваете вы. Выдача сервера, SMS и возможность входа в Telegram зависят от внешних сервисов. Telegram может потребовать официальное мобильное приложение; вход в Desktop для нового аккаунта не гарантируется.

## 7. Сохраните доступ до перезагрузки

Сохраните onion-адрес, пароль и ключ аутентификатора в защищённом месте. Откройте инструкцию на другом устройстве или подготовьте бумажную копию. Не храните единственный экземпляр доступа в той среде, из которой ещё предстоит войти. Подробности: [восстановление](docs/RECOVERY.md).

## 8. Входите ежедневно

На этапе «Ежедневный вход» выберите Windows, macOS, Linux, Tails, Android или iPhone согласно подсказкам своего устройства. Для входа с компьютера нужен поддерживаемый официальный Tor Browser; на Linux ARM64 в этом выпуске используйте другой совместимый компьютер. Откройте Tor, затем свой сохранённый onion-адрес, введите пароль и одноразовый код. Мастер заново устанавливать не нужно. После подготовки Android закройте USB-доступ и отключите отладку на телефоне.

Для файлов Workstation создаёт очищенные копии; исходники сохраняются. Очистка метаданных не удаляет имена и другие сведения из самого текста, картинки или видео. Перед передачей откройте и проверьте копию. Обычный обмен файлами между локальным устройством и удалённым кабинетом не объявляется встроенной возможностью noVNC.

Если система показывает ошибку, сохраните краткое описание и очищенный снимок без секретов. Не продолжайте опасную операцию, когда выбранный носитель, серверный ключ или комплект не совпадает с ожидаемым.

## 9. Открывайте сайты из удалённого браузера

В рабочей среде Whonix Workstation откройте меню приложений → Tor Browser. Проверьте Tor именно в этом удалённом окне, затем открывайте HTTPS-сайт и входите в свой аккаунт. Сайт узнаёт аккаунт после входа; Tor не стирает его историю и не делает владельца сервера доверенным автоматически. [Каждое действие и его результат](docs/WEBSITES.md).

## Покупка XMR и расходы

Если у вас USDT, начните с [отдельной инструкции USDT → XMR](docs/MONERO-USDT.md). Перед покупкой сервера и номера откройте [месячную смету](docs/BUDGET.md). Реальные условия обмена, сети и суммы проверьте до перевода.
