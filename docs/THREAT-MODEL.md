# Модель угроз и ограничения

Цель OnionDesk — помочь владельцу пройти проверяемый маршрут подготовки и доступа к отдельной рабочей среде. Проект не обещает полную анонимность, неуязвимость или отсутствие следов у всех участников.

| Риск | Предусмотренное ограничение | Что остаётся вне гарантии |
|---|---|---|
| Подмена установочного компонента | Закреплённые каталоги, размер/хеш и подпись официального издателя; отказ при несоответствии. | Компрометация издателя, сборочной машины или самого устройства владельца. |
| Подмена сервера | Проверка SSH-ключа и явное подтверждение установки. | Недобросовестный провайдер, аппаратный доступ и ложные сведения о KVM. |
| Непреднамеренный открытый сетевой вход | Loopback listeners, onion ingress и runtime-аудит конфигурации. | Неиспытанный host, изменённая конфигурация после аудита и внешняя инфраструктура. |
| Чужой локальный сайт вызывает API | Проверки Host/Origin/nonce, точные схемы запросов и ограничения параллельных действий. | Вредоносный локальный процесс и компрометация ОС. |
| Утрата кошелька | Защищённое хранилище и проверка сохранения 25 слов. | Потерянная резервная фраза, раскрытый пароль, фотографии/копии слов. Приложение не восстанавливает забытые секреты. |
| Стирание чужого USB | Выбор носителя и отдельное подтверждение перед записью. | Ошибка выбора владельцем, изменение устройства и непроверенная аппаратная среда. |
| Личные сведения в передаваемом документе | Очистка метаданных создаёт отдельную проверенную копию, сохраняя исходник. | Текст, изображение, голос, видимые имена и другая информация в содержимом. |
| Связывание личности с аккаунтом | Инструкции разделяют маршруты и предупреждают о личных аккаунтах. | Телефон, SMS, платежи, Telegram, поведенческие признаки и записи внешних сервисов. |
| Лишний доступ Android по USB | Подтверждение устройства владельцем и завершение USB-доступа. | Состояние телефона, OEM, отладка, оставленная включённой после подготовки. |

Доверенные части: собственное устройство, проверенный релиз, издатели официальных компонентов и подтверждённые ключи. Серверный провайдер и удалённые сервисы имеют отдельные возможности наблюдения. Tor меняет сетевой маршрут; он не исправляет заражённую ОС, не очищает документ и не делает личный аккаунт анонимным.

Приложение не исполняет произвольные RPC кошелька и не отправляет XMR. Доступ к seed временный, показ требует отдельного действия, UI очищает отображение. Освобождение Python-объектов не является гарантированным физическим стиранием всех копий RAM.

Платформенные ограничения: Mac Intel не покрыт; Tails USB не загружается на Apple Silicon; Linux ARM64 не имеет проверенного стабильного Tor Browser; реальный Windows UAC, Linux polkit и USB на целевых устройствах требуют отдельных испытаний. Границы фактических результатов указаны в [матрице](VERIFICATION.md).
