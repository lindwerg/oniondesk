# Что проверено в этом экспорте

Обновлено: **2026-10-17**.

Состояние: **закрытый предварительный выпуск**. [Кнопки ZIP](../README.md#программа-для-вашего-компьютера) закреплены за конкретными коммитами: Windows использует прежний опубликованный комплект, Mac и обе архитектуры Linux — опубликованные R4. Приватность репозитория подтверждена при публикации и повторном чтении. Локальные проверки исправлений R4 описаны отдельно от прежней доставки R3. Полное получение всех четырёх новых ZIP из GitHub и запуск на каждой физической ОС не подтверждены. Необработанные журналы и данные реальных устройств в репозиторий не включены.
