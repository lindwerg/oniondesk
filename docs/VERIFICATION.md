# Что проверено в этом экспорте

Состояние: **локальный черновик с зафиксированным интерфейсом, до независимого review и source push**. Таблица не переносит результат прежнего рабочего комплекта на новый Git-экспорт автоматически. Необработанные журналы и данные реальных устройств в репозиторий не включены.

Frozen UI и исходный backend manifest v3 подтверждены; runtime-модули совпали. Результаты будут обновлены после фактического прогона с числом тестов, пропусками, платформой, версией источников и существенными ограничениями. В README нет badge об успешном CI. Платные GitHub runners и другие платёжные действия не запускались.

В тестах встречаются известные учебные seed/password/OTP, примеры IP и генерируемые одноразовые ключи. Их назначение — проверка защитных отказов, тесты кошелька и криптографические fixtures. Они не являются рабочими доступами и **никогда не подходят для хранения средств или эксплуатации**. Общие адреса loopback, RFC1918 и документационные IP являются фикстурами/сетевыми правилами, а не сведениями о личном сервере.
