# Состав исходников и правила экспорта

Это отдельное дерево исходников, собранное по разрешённым классам файлов. Копирование всей рабочей папки не выполнялось.

Разрешены: верхнеуровневые исходники `client`, `server`, `frontend`; точные файлы UI и локальные шрифты с лицензией; сценарии тестов и unit-fixtures; интерфейсные `assets/microsteps`, `assets/steps`, известные brand-файлы; исходные `LICENSES`; только code-pinned публичные signing metadata и лицензии для developer recipe. Точные имена, размеры и SHA-256 перечислены в [manifest](EXPORT-MANIFEST.json). Изображения README отдельно выбраны из синтетического стенда и просмотрены. Дополнительно включены только 26 точечно просмотренных настоящих PNG из [GUIDE_SHOTS allowlist](GUIDE-IMAGE-MANIFEST.json), без импорта всей папки screenshots.

Исключены: `work`, output/build folders, кеши, `.git` исходного окружения, `client/data`, пользовательские хранилища, `OnionDesk-Data`, серверные ключи, seed владельца, ADB state, реальные IP/device IDs, личные пути, логи, downloaded executables/archives, дисковые IMG/ISO/VM и необработанные screenshots/proofs. Ссылки среди копируемых ресурсов не разрешаются автоматически.

Известные учебные пароли, seed-фрагменты, примерные IP и одноразовые ключи внутри тестов сохраняются для воспроизводимости и помечены в [матрице](VERIFICATION.md) как **TEST ONLY**. Они не пригодны для живых систем или средств. Официальные public signing fingerprints и vendor license attribution не являются секретами; лицензии издателей не редактируются ради удаления имён их авторов.

Финальный gate перед отправкой: синхронизация замороженного UI, повторный manifest, scan содержимого и имён/метаданных, review полного diff и проверка private. Текущий manifest сам по себе не является результатом независимого security review.
