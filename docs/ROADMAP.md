# Ближайшие шаги

Это план, а не список завершённых возможностей.

1. Завершить независимый review синхронизированного frozen UI и исходников.
2. Проверить сетевое восстановление большого Data-комплекта и полную build-рецептуру чистого checkout на целевых ОС.
3. Собрать полные пакеты по ОС; проверить доставку через private GitHub archives с LFS без удаления Tails/Android и других обещанных сценариев. До upload подтвердить квоту/бюджет и допустимые расходы.
4. Проверить целевые ОС и настоящие UAC/polkit/USB, отдельно отметить поддерживаемые устройства.
5. Испытать полный серверный маршрут на совместимом KVM host, включая cold boot и текущий runtime-аудит.
6. Выполнить финальный security/PII review и выпустить private Release с настоящими кнопками и хешами.
7. Уточнить путь Linux ARM64 и статус Mac Intel, не выдавая частичную поддержку за готовую платформу.
8. Решения о публичности, лицензии оригинального кода, внешних участниках и платном CI принимать отдельно с владельцем.
