# Загрузить OnionDesk

**Статус: закрытый релиз готовится.** В этой версии страницы нет активных ссылок на ещё не загруженные файлы. Доступ к будущим файлам получат только пользователи с доступом к private-репозиторию.

<a id="windows"></a>
## Windows x64

Планируемая кнопка: **Скачать полный комплект Windows**. ZIP будет содержать `OnionDesk-Setup.exe` вместе со всеми требуемыми соседними файлами. После полного извлечения установщик открывается двойным нажатием, затем приложение запускается ярлыком. Окончательная структура и ссылка закрепляются после проверки. Встроенные зависимости не требуют отдельной установки Python.

Предварительные проверки под Wine не подтверждают настоящий UAC, защиту BitLocker, работу GUI и физический USB на Windows. До релиза они перечисляются отдельно.

<a id="macos"></a>
## macOS Apple Silicon

Планируемая кнопка: **Скачать полный комплект Mac Apple Silicon**. ZIP будет содержать `OnionDesk.app` со всеми необходимыми ресурсами. Требуется macOS 15+. Имя автоматически создаваемого GitHub-архива зависит от distribution commit; ссылка появится после проверки. Способ доставки большого офлайн-комплекта описан в [плане релиза](RELEASE-PLAN.md).

Mac Intel не покрыт готовым пакетом. Локальная подпись ad-hoc не является Developer ID или Apple notarization. Перед скачиванием итоговая страница покажет состояние подписи и фактические ограничения.

<a id="linux"></a>
## Linux

Планируемые кнопки: **Полный комплект Linux Intel/AMD x86_64** и **Полный комплект Linux ARM64 aarch64**. После полного извлечения ZIP открывается `OnionDesk/OnionDesk` вместе с поставляемыми соседними файлами и Data. Окончательная структура и ссылки появятся после проверки. Нужны графический рабочий стол, браузер и glibc 2.36+.

На ARM64 отсутствует проверенная стабильная официальная сборка Tor Browser. Это блокер объявления полной готовности соответствующего пользовательского маршрута, даже если ELF-программа запускается. Настоящий polkit, шифрование LUKS и USB требуют проверки на целевой системе.

## Tails, Android и iPhone

Эти сценарии остаются частью проекта. Tails USB подготавливается настольным мастером для совместимого x86_64 компьютера; Android поддерживает подготовку по USB с личным подтверждением владельца; iPhone использует отдельную инструкцию входа. Для телефонов не обещается настольный установщик. Отдельные мобильные действия не подтверждают анонимность устройства или готовность всей серверной цепочки.

## Что должно появиться у каждого файла

- Реальная кнопка, ведущая на проверенный полный ZIP конкретного distribution commit в private GitHub.
- ОС, архитектура, требования, версия и точный размер.
- Фактически вычисленный SHA-256; проверка подписи издателя для включённых официальных компонентов.
- Информация о подписи приложения и границах проведённых испытаний.
- Простой запуск без ручной сборки и сохранение всех заявленных сценариев.

Полный архив около 7 GB не подходит как один asset GitHub Release. Подтверждён вариант полных OS-архивов GitHub с настоящими LFS-файлами. Сейчас настройки и загрузка LFS не выполнялись: сначала нужны окончательные native-пакеты, проверка квоты/бюджета и разрешение на возможные расходы. Скачивать такой private-архив нужно в браузере с доступом к репозиторию; никакие токены в комплект не встраиваются. [Требования и ограничения доставки](RELEASE-PLAN.md).
