# Комплекты OnionDesk: статус и первое открытие

Это бесплатный **закрытый предварительный выпуск** для Windows x64, Mac Apple Silicon, Linux x64 и Linux ARM64. Нужен аккаунт GitHub с доступом к приватному репозиторию; публичной загрузки нет. Полное получение и запуск всех четырёх комплектов ещё не подтверждены. [Точные границы проверок](VERIFICATION.md).

1. **Выберите ОС и скачайте ZIP по ссылке ниже.** Комплект занимает несколько ГБ; освободите не менее **20 ГБ** и дождитесь полной загрузки.
2. **Распакуйте ZIP целиком в одну папку.** Сохраните все файлы, включая `.oniondesk`, рядом с программой. В Windows папка с точкой может быть видна.
3. **Откройте значок программы и подождите проверки файлов и окна мастера.** Python, терминал и самостоятельная сборка для этого не нужны.

GitHub Source code ZIP содержит исходники. Для установки выбирайте комплект своей ОС ниже.

**[Видео, презентация и руководство уже опубликованы в выпуске v5](https://github.com/lindwerg/oniondesk/releases/tag/preview-2026.10.16-v5).** Все шесть вложений повторно скачаны из GitHub: размеры и контрольные суммы совпали. Это проверка доставки учебных материалов; она не подтверждает установку программы на каждой ОС.

<a id="windows"></a>
## Windows x64

**[Скачать ZIP для Windows x64](https://github.com/lindwerg/oniondesk/archive/027269c31225d8e7c3907747cff5d6e79ca79962.zip)** · закрытый preview. Получение полного Windows-архива и запуск на настоящей Windows пока не подтверждены.

1. Нажмите скачанный ZIP правой кнопкой мыши и выберите «Извлечь всё».
2. Откройте полученную папку. Не перемещайте программу отдельно: рядом нужна папка `.oniondesk`.
3. Дважды нажмите `OnionDesk-Windows.exe` и дождитесь проверки файлов и окна мастера. Системные разрешения подтверждает владелец компьютера.

Программа собрана для x64. Предварительные проверки под Wine не подтверждают настоящий UAC, Authenticode, защиту BitLocker, работу окон и физический USB на Windows; эти ограничения сохраняются у предварительного выпуска.

<a id="macos"></a>
## Mac Apple Silicon · macOS 15 и новее

**[Скачать ZIP для Mac Apple Silicon](https://github.com/lindwerg/oniondesk/archive/a9d7dbb1d1c60e23089de7578453b9d4b35ecca4.zip)** · macOS 15+, закрытый preview. Первое открытие исправленной версии, переход к следующему действию и штатное закрытие проверены локально. Полная загрузка именно этого нового ZIP и первое открытие через Gatekeeper ещё не проверены.

1. Дважды нажмите скачанный ZIP и откройте распакованную папку.
2. Дважды нажмите `OnionDesk.app` и дождитесь проверки файлов. Сохраните папку `.oniondesk` рядом с приложением; переносите весь комплект целиком.
3. Если macOS сообщает, что разработчик не проверен, сначала убедитесь, что получили именно этот выпуск из репозитория OnionDesk.
4. Откройте «Системные настройки → Конфиденциальность и безопасность». Найдите предупреждение именно об OnionDesk и нажмите «Всё равно открыть» / **Open Anyway**, если доверяете этому выпуску.
5. Подтвердите повторный системный запрос. Результат — окно OnionDesk. В дальнейшем открывайте приложение обычным двойным нажатием.

Это порядок для предупреждения о непроверенном разработчике. Сообщение о повреждении или вредоносном ПО требует отдельной проверки. У пакета локальная подпись ad-hoc; Apple notarization и подписи Developer ID нет. Готового варианта для Mac Intel нет. [Официальная инструкция Apple со снимками окон](https://support.apple.com/ru-ru/102445).

<a id="linux"></a>
## Linux с графическим рабочим столом

<a id="linux-x64"></a>
### Linux Intel / AMD x64

**[Скачать ZIP для Linux x64](https://github.com/lindwerg/oniondesk/archive/57fe7ff4ca294eb4a34fdb5ba35b707122dd5788.zip)** · закрытый preview для обычного 64-битного Linux Desktop. Запуск мастера проверен в виртуальной тестовой среде; полный новый ZIP и физический компьютер x64 отдельно не проверены.

Для отдельного Tor Browser нужны системные GTK3 и ALSA. Проверка соединения официального браузера описана отдельно в [результатах проверок](VERIFICATION.md); она не подтверждает весь путь настройки сервера.

<a id="linux-arm64"></a>
### Linux ARM64

**[Скачать ZIP для Linux ARM64](https://github.com/lindwerg/oniondesk/archive/3cf25cfa68a7ff8966d79f487447e766a9ad1a09.zip)** · подготовка и инструкции, закрытый preview. Первое и повторное открытие мастера, отмена и повторный запуск проверены в тестовой среде. Полный новый ZIP и физический ARM-компьютер отдельно не проверены.

Linux ARM64 в этом выпуске предназначен для подготовки и просмотра инструкций: этап с официальным Tor Browser отключён. Для полного маршрута используйте компьютер Intel/AMD x86-64 или поддерживаемый Mac.

После полной загрузки Linux-комплекта:

1. Выберите x64 для Intel/AMD или ARM64 для соответствующего 64-битного ARM-компьютера.
2. Полностью распакуйте ZIP средствами своей системы.
3. Сохраните папку `.oniondesk` рядом с программой. В файловом менеджере она может быть скрыта.
4. Откройте `OnionDesk-Linux-x64` или `OnionDesk-Linux-ARM64`. Если файловый менеджер предлагает варианты, выберите запуск программы. Разрешение запуска исполняемого файла зависит от файлового менеджера и вашей системы.

Нужны браузер, графический рабочий стол и glibc 2.36+. Для Tor Browser на Linux x64 дополнительно нужны системные GTK3 и ALSA. Доступность этапа Tor Browser зависит от архитектуры, как указано выше. Системные разрешения, шифрование LUKS и USB требуют проверки на целевой системе.

## Телефон и флешка

Android и iPhone используются для входа в уже подготовленный кабинет. Настольный мастер запускается на Windows, Mac или Linux. Для Android предусмотрена подготовка по USB с личным подтверждением доверия на телефоне; iPhone проходит по отдельной инструкции.

Tails USB подготавливается мастером для совместимого компьютера Intel/AMD x86_64. На Apple Silicon Tails не загружается; там можно подготовить флешку для другого совместимого компьютера.

## Если скачивание не открывается

- **GitHub просит войти или показывает 404:** войдите в аккаунт с доступом к этому приватному проекту; при отсутствии доступа обратитесь к владельцу.
- **Архив программы не завершил загрузку:** не запускайте частично скачанный комплект. Проверьте свободное место и повторите загрузку своей ОС; успешное получение учебных материалов v5 не подтверждает получение программы.
- **Не удаётся загрузить большие файлы:** у закрытой раздачи GitHub есть общая месячная квота. Обратитесь к владельцу репозитория; платного перерасхода для этой раздачи не включали, неограниченные скачивания не обещаются.

<summary>Технический статус доставки</summary>

Ссылки выше закреплены за неизменяемыми коммитами. Windows использует прежний опубликованный комплект; Mac и обе архитектуры Linux — опубликованные в приватном репозитории исправления R4. У Mac сверены все 568 удалённых записей и фактически считаны пять новых файлов. У каждой Linux-ветки сверено полное дерево; новые обычные файлы считаны обратно с проверкой SHA-256, Git OID и размеров. Полное скачивание всех четырёх новых ZIP и полный GUI-прогон всех ОС не заявляются. [Подробные проверки](VERIFICATION.md).

Прежний контрольный [Mac ZIP R3](https://github.com/lindwerg/oniondesk/archive/59bf58813c5f19384b56e01ede130666ef845a72.zip) полностью получен и исследован: обычная распаковка сохраняла точные байты, но давала права 775/664, которые защита R3 отклоняла. Исправление R4 проверяет исходные байты и создаёт собственную защищённую копию; отключать проверки или менять права вручную не требуется. Локальный первый запуск R4 проверен с такими правами распаковки, но новый полный R4 ZIP из GitHub не скачивался.

При первом запуске мастер проверяет и восстанавливает файлы в локальное хранилище, при следующих использует сохранённую копию. Не удаляйте исходный комплект во время подготовки. Git LFS имеет общую включённую месячную квоту передачи 10 GiB; бюджет платного перерасхода остаётся $0. Счётчик usage может отставать от фактических передач, поэтому показание 0 не означает неограниченный остаток.

Учебные материалы v5 опубликованы и прошли повторное скачивание всех шести вложений с проверкой размеров и SHA-256. Старые distribution-ветки V4 сохраняются как прежние экспериментальные варианты. Наблюдения и условия доставки — в [плане выпуска](RELEASE-PLAN.md).
