# Комплекты OnionDesk: статус и первое открытие

Это бесплатный **закрытый предварительный выпуск**. Готовые комплекты проходят проверку полной загрузки. Ссылки на них появятся после успешного получения и проверки всех файлов; сейчас полные GitHub ZIP не объявлены готовым способом установки.

Выберите систему своего компьютера ниже. Инструкции первого открытия сохранены для момента, когда комплект будет полностью получен и проверен. В готовом комплекте предусмотрены программа, её ресурсы и PDF-руководство; Python и самостоятельная сборка не нужны. Для доступа к закрытому выпуску потребуется аккаунт GitHub, которому владелец дал доступ к репозиторию.

<a id="windows"></a>
## Windows x64

**Статус: полная загрузка проверяется. Ссылка на комплект пока не включена.** После успешной загрузки:

1. Нажмите скачанный ZIP правой кнопкой мыши и выберите «Извлечь всё».
2. Откройте полученную папку. Не перемещайте из неё установщик отдельно: рядом нужна папка `.oniondesk`, которая может быть скрыта проводником.
3. Дважды нажмите `OnionDesk-Windows.exe` и завершите установку. Запрос разрешения Windows подтверждает владелец компьютера.
4. Откройте OnionDesk созданным ярлыком. Должно появиться окно мастера с первым действием.

Установщик собран для x64. Предварительные проверки под Wine не подтверждают настоящий UAC, защиту BitLocker, работу GUI и физический USB на Windows; эти ограничения сохраняются у предварительного выпуска.

<a id="macos"></a>
## Mac Apple Silicon · macOS 15 и новее

**Статус: полная загрузка проверяется. Ссылка на комплект пока не включена.** После успешной загрузки:

1. Дважды нажмите скачанный ZIP и откройте распакованную папку.
2. Дважды нажмите `OnionDesk.app`. Все ресурсы этого варианта встроены в приложение.
3. Если macOS сообщает, что разработчик не проверен, сначала убедитесь, что получили именно этот выпуск из репозитория OnionDesk.
4. Откройте «Системные настройки → Конфиденциальность и безопасность». Найдите предупреждение именно об OnionDesk и нажмите «Всё равно открыть» / **Open Anyway**, если доверяете этому выпуску.
5. Подтвердите повторный системный запрос. Результат — окно OnionDesk. В дальнейшем открывайте приложение обычным двойным нажатием.

Это порядок для предупреждения о непроверенном разработчике. Сообщение о повреждении или вредоносном ПО требует отдельной проверки. У пакета локальная подпись ad-hoc; Apple notarization и подписи Developer ID нет. Готового варианта для Mac Intel нет. [Официальная инструкция Apple со снимками окон](https://support.apple.com/ru-ru/102445).

## Linux с графическим рабочим столом

<a id="linux-x64"></a>
### Linux Intel / AMD x64

**Статус: полная загрузка проверяется. Ссылка на комплект пока не включена.**

<a id="linux-arm64"></a>
### Linux ARM64

**Статус: полная загрузка проверяется. Ссылка на комплект пока не включена.** Также отсутствует проверенный маршрут с официальным Tor Browser для этой архитектуры.

После получения полного проверенного Linux-комплекта:

1. Выберите x64 для Intel/AMD или ARM64 для соответствующего 64-битного ARM-компьютера.
2. Полностью распакуйте ZIP средствами своей системы.
3. Сохраните папку `.oniondesk` рядом с программой. В файловом менеджере она может быть скрыта.
4. Откройте `OnionDesk-Linux-x64` или `OnionDesk-Linux-ARM64`. Если файловый менеджер предлагает варианты, выберите запуск программы. Разрешение запуска исполняемого файла зависит от файлового менеджера и вашей системы.

Нужны браузер, графический рабочий стол и glibc 2.36+. На ARM64 отсутствует проверенная стабильная официальная сборка Tor Browser — полный маршрут не объявлен готовым. Настоящие polkit, шифрование LUKS и USB требуют проверки на целевой системе.

## Телефон и флешка

Android и iPhone используются для входа в уже подготовленный кабинет. Настольный мастер запускается на Windows, Mac или Linux. Для Android предусмотрена подготовка по USB с личным подтверждением доверия на телефоне; iPhone проходит по отдельной инструкции.

Tails USB подготавливается мастером для совместимого компьютера Intel/AMD x86_64. На Apple Silicon Tails не загружается; там можно подготовить флешку для другого совместимого компьютера.

## Если скачивание не открывается

- **GitHub просит войти или показывает 404:** войдите в аккаунт с доступом к этому приватному проекту; при отсутствии доступа обратитесь к владельцу.
- **Архив не завершил загрузку:** не запускайте частично скачанный комплект. Полная загрузка GitHub ZIP сейчас не подтверждена; дождитесь проверенного способа получения комплекта.
- **Не удаётся загрузить большие файлы:** у закрытой раздачи GitHub есть месячная квота. Обратитесь к владельцу репозитория; платного перерасхода для этой раздачи не включали.
