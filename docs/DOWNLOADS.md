# Скачать и открыть OnionDesk

Обновлено: **2026-10-17**.

Это бесплатный выпуск с открытым исходным кодом. Программы опубликованы обычными вложениями [GitHub Release](https://github.com/lindwerg/oniondesk/releases/tag/runtime-data-2026.10.17-v6); аккаунт GitHub не нужен.

1. **Скачайте небольшой ZIP для своего компьютера** по ссылке в таблице.
2. **Распакуйте ZIP целиком** в одну папку и сохраните всё содержимое.
3. **Откройте значок программы и подождите.** OnionDesk сам загрузит около **3,8 ГБ**, проверит файлы и откроет мастер. Для первого запуска нужны интернет и не менее **20 ГБ** свободного места. Python, терминал и самостоятельная сборка не нужны.

| Ваш компьютер | Скачать ZIP | Открыть после распаковки |
|---|---|---|
| Windows x64 | [5,4 МБ](https://github.com/lindwerg/oniondesk/releases/download/runtime-data-2026.10.17-v6/OnionDesk-Windows-x64.zip) | `OnionDesk-Windows.exe` |
| Mac Apple Silicon, macOS 15+ | [6,9 МБ](https://github.com/lindwerg/oniondesk/releases/download/runtime-data-2026.10.17-v6/OnionDesk-Mac-Apple-Silicon.zip) | `OnionDesk.app` |
| Linux Intel / AMD x64 | [19,1 МБ](https://github.com/lindwerg/oniondesk/releases/download/runtime-data-2026.10.17-v6/OnionDesk-Linux-x64.zip) | `OnionDesk-Linux-x64` |
| Linux ARM64 | [18,3 МБ](https://github.com/lindwerg/oniondesk/releases/download/runtime-data-2026.10.17-v6/OnionDesk-Linux-ARM64.zip) | `OnionDesk-Linux-ARM64` — подготовка и инструкции |

Размеры округлены в десятичных МБ. Все четыре ZIP повторно скачаны без авторизации: точные размеры и SHA-256 совпали. Это проверка доставки; фактические запуски и их границы перечислены в [результатах проверок](VERIFICATION.md).

## Что происходит при первом открытии

Начальная загрузка идёт с GitHub по обычному HTTPS и не заявляется как Tor-трафик. Программа сама получает две части данных; выбирать или склеивать их вручную не нужно. Полный поток — **3 776 694 788 bytes**. Загрузчик проверяет закреплённые размеры и SHA-256, затем восстанавливает файлы в собственный локальный кэш. Место нужно для загруженных объектов и восстановленной программы, поэтому рекомендовано не менее 20 ГБ.

Подготовку можно отменить и повторить. Если загрузка прервалась, снова откройте программу при работающем интернете. При следующих открытиях используется проверенный кэш, в том числе без сети; Tor и внешние сервисы по-прежнему требуют соединения. Повреждённые или неподтверждённые файлы не должны запускаться.

Сохраняйте весь распакованный комплект, включая скрытую `.oniondesk` с лицензиями. На Mac ресурсы запуска находятся внутри `OnionDesk.app`; внешний runtime-пул рядом с ним не требуется. **GitHub Source code ZIP содержит исходники. Для установки используйте ZIP своей ОС из таблицы.**

<a id="windows"></a>
## Windows x64

1. Нажмите скачанный ZIP правой кнопкой мыши и выберите «Извлечь всё».
2. Откройте полученную папку и дважды нажмите `OnionDesk-Windows.exe`.
3. Дождитесь автоматической подготовки и окна мастера. Системные разрешения подтверждает владелец компьютера.

Полная загрузка нового ZIP подтверждена. Проверки R5 на целевой Windows ещё выполняются; успешный прогон пока не заявляется. Прежние проверки под Wine не подтверждают настоящий UAC, Authenticode, BitLocker и физический USB.

<a id="macos"></a>
## Mac Apple Silicon · macOS 15 и новее

1. Дважды нажмите скачанный ZIP и откройте распакованную папку.
2. Дважды нажмите `OnionDesk.app` и дождитесь автоматической подготовки.
3. Если macOS сообщает, что разработчик не проверен, сначала убедитесь, что получили именно этот выпуск из репозитория OnionDesk.
4. Откройте «Системные настройки → Конфиденциальность и безопасность». Найдите предупреждение именно об OnionDesk и нажмите «Всё равно открыть» / **Open Anyway**, если доверяете этому выпуску.
5. Подтвердите повторный системный запрос. Результат — окно OnionDesk. В дальнейшем открывайте приложение обычным двойным нажатием.

Это порядок для предупреждения о непроверенном разработчике. Сообщение о повреждении или вредоносном ПО требует отдельной проверки. Пакет имеет локальную подпись ad-hoc, без Apple notarization и Developer ID. Готового варианта для Mac Intel нет. [Официальная инструкция Apple](https://support.apple.com/ru-ru/102445).

На Mac фактически проверены загрузка обеих удалённых частей целиком, восстановление, первое окно, прокрутка, переход к следующему действию и штатное закрытие. Повторный запуск worker из проверенного кэша прошёл с запретом сети; отдельно повторно открыто и закрыто нативное окно. **Путь Safari → распаковка с quarantine → Gatekeeper / App Translocation не проверен.** Строгая глубокая проверка локальной подписи прошла успешно.

<a id="linux"></a>
## Linux с графическим рабочим столом

Нужны браузер, графический рабочий стол и glibc 2.36+. Для отдельного Tor Browser на Linux x64 дополнительно нужны системные GTK3 и ALSA.

1. Выберите x64 для Intel/AMD или ARM64 для соответствующего 64-битного ARM-компьютера.
2. Полностью распакуйте ZIP средствами своей системы.
3. Откройте `OnionDesk-Linux-x64` или `OnionDesk-Linux-ARM64`. Если файловый менеджер предлагает варианты, выберите запуск программы. Разрешение запуска исполняемого файла зависит от файлового менеджера и вашей системы.
4. Дождитесь автоматической подготовки и окна мастера.

<a id="linux-x64"></a>
### Linux Intel / AMD x64

Полная загрузка нового ZIP подтверждена. Новые проверки R5 в CI ещё выполняются; успешный результат пока не заявляется. Прежние локальные проверки мастера и отдельного официального Tor Browser сохранены в [истории проверок](VERIFICATION.md).

<a id="linux-arm64"></a>
### Linux ARM64

Полная загрузка нового ZIP подтверждена. Новые проверки R5 в CI ещё выполняются; успешный результат пока не заявляется. Этот вариант предназначен для подготовки и просмотра инструкций: этап с официальным Tor Browser на этой архитектуре отключён. Для полного маршрута используйте компьютер Intel/AMD x86-64 или поддерживаемый Mac.

Системные разрешения, LUKS и USB требуют отдельной проверки на целевой системе.

## Телефон, флешка и сервер

Android и iPhone используются для входа в уже подготовленный кабинет; настольный мастер на телефон не устанавливается. Официальный Tor Browser 15.0.25 со Snowflake получил `IsTor: true` по HTTPS в Android API 35 ARM64 эмуляторе. Физический телефон и подготовка по USB не проверены; для iPhone полный путь не подтверждён.

Tails запускался в QEMU с проверкой Tor и HTTPS. Физическая запись и загрузка USB не проверены. Tails USB предназначен для совместимого Intel/AMD x86_64 компьютера; Apple Silicon этим сценарием не покрыт.

На Debian 13 проверены настоящий KVM и запуск QEMU от непривилегированного пользователя, подпись официальных образов Whonix и оба диска. Установка удалённого кабинета завершилась ошибкой и ещё не готова к заявлению об успешном полном пути. Оплаченный сервер, SMS и кошелёк со средствами не проверялись.
